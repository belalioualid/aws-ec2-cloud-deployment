# AWS EC2 Cloud Deployment

## Project Overview
This project aims to deploy a simple web application on an AWS EC2 instance.

## Objectives
- Understand cloud computing fundamentals.
- Launch and configure an EC2 instance.
- Configure network access using Security Groups.
- Install and configure an Nginx web server.
- Deploy a static website.
- Document the deployment process.

## Technologies
- AWS EC2
- Linux
- Nginx
- Git
- GitHub
- HTML

## Project Architecture

User → Internet → AWS Security Group → EC2 Instance → Nginx → Website
